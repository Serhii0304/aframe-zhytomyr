# A-FRAME — лендінг каркасного будівництва

Односторінковий рекламний сайт для послуг з будівництва будинків А-фрейм, каркасних
і модульних будинків, бань, ангарів та парканів у Житомирській і Київській областях.

**Живий сайт:** https://serhii0304.github.io/aframe-zhytomyr/

Статичний сайт без збірки й залежностей: чистий HTML, CSS і JavaScript.
Відкривається будь-де — GitHub Pages, Cloudflare Pages, звичайний хостинг.

---

## Структура

```
index.html            вся сторінка
404.html              сторінка «не знайдено»
favicon.svg           іконка вкладки
assets/css/style.css  стилі
assets/js/main.js     меню, галерея, лайтбокс, FAQ, форма
assets/img/           фотографії (jpg + webp, по два розміри)
build_images.py       перегенерація фото з оригіналів у _source/
robots.txt            дозвіл для пошукових систем
sitemap.xml           карта сайту
```

## Що треба заповнити своїми даними

Нижче — усе, що зараз стоїть як заготовка. Пошук по файлу зробить це за хвилини.

### 1. Ціни (за бажанням)

У блоці «Формати будівництва» ціни навмисно приховані. Щоб показати ціну на картці —
знайдіть у `index.html` коментар `ЗМІНИТИ: коли визначитесь із ціною` і розкоментуйте рядок:

```html
<p class="format__price">від <b>450 000</b> ₴ під ключ</p>
```

Поки ціни немає, кнопка веде на форму прорахунку — це робочий і чесний варіант.

### 2. Куди приходять заявки з форми

Заявки йдуть на пошту **Avessalom7@gmail.com** через [formsubmit.co](https://formsubmit.co) —
без реєстрації та без ключів. Адреса задана в `assets/js/main.js`:

```js
var CONFIG = {
  phone: '+380970864989',
  phoneLabel: '097 086 4989',
  formEmail: 'Avessalom7@gmail.com'
};
```

#### ⚠️ Першу заявку треба активувати

FormSubmit не доставляє листи, поки власник пошти не підтвердить адресу:

1. Заповніть форму на сайті й натисніть «Отримати прорахунок».
2. На `Avessalom7@gmail.com` прийде лист від FormSubmit із кнопкою активації.
3. Натисніть її. Після цього всі наступні заявки приходять одразу.

**Без цього кроку форма мовчки не працює.**

#### Приховати адресу від спам-ботів

Зараз пошта видима у коді сторінки. Після активації FormSubmit дає постійний
код виду `xxxxxxxxxxxx` — його можна підставити замість адреси:

```js
formEmail: 'xxxxxxxxxxxx'   // замість Avessalom7@gmail.com
```

Код видно в особистому кабінеті FormSubmit або в листі активації.

Якщо `formEmail` залишити порожнім, форма перемикається на запасний варіант —
відкриває SMS із готовим текстом заявки. Працює лише на телефонах.

### 3. Телефон і месенджери

Номер `+380970864989` зустрічається в `index.html` (шапка, контакти, підвал, мобільна
панель, JSON-LD) та в `assets/js/main.js`. Замінюйте всюди разом.

### 4. Viber і Telegram

Кнопки месенджерів відкривають застосунок на телефоні. Це не звичайні
посилання, а команди `viber://` та `tg://` — тому:

- на Android використовується `intent://`, яке саме поверне людину на сайт,
  якщо застосунок не встановлений;
- на решті платформ спрацьовує таймер: якщо за 1,8 секунди застосунок не
  відкрився, зʼявляється підказка з номером телефону.

**Перевірте, що на номері справді зареєстровані Viber і Telegram.** Якщо
якогось немає — приберіть кнопку з `index.html`, інакше людина натисне
в порожнечу.

Якщо у власника є **username у Telegram** (`@nickname`), надійніше замінити
кнопку на звичайне посилання — воно відкриється навіть без застосунку:

```html
<a class="btn btn--outline" href="https://t.me/nickname" target="_blank" rel="noopener">Telegram</a>
```

Адреса виду `t.me/+380…` **не працює** — Telegram читає її як запрошення
до групи, а не як номер телефону.

### 5. Графік роботи

`Пн–Нд, 8:00–20:00` у блоці контактів і в JSON-LD — поставте свій реальний.

### 6. Обіцянки, які треба підтвердити

В оголошенні на OLX цих даних не було — я поставив загальноприйняті для галузі
формулювання. **Перевірте кожну і виправте під свою реальну практику**, бо це
публічні зобов'язання перед клієнтом:

| Де | Що написано | Перевірити |
|---|---|---|
| Блок «Чому нам довіряють» | «Договір і фіксована ціна» | Ви справді укладаєте письмовий договір? |
| Блок «Чому нам довіряють» | «Поетапна оплата за завершеним етапом» | Такий у вас порядок розрахунку? |
| Блок «Чому нам довіряють» | «З власним інструментом і бригадою» | Бригада своя чи наймана? |
| Контакти | «Пн–Нд, 8:00–20:00» | Ваш реальний графік |
| Форма | «Передзвонюємо протягом робочого дня» | Встигаєте? |
| Комплектація «під ключ» | 12 пунктів базового складу робіт | Приберіть те, чого не робите |
| Етапи роботи | 6 кроків, зокрема виїзд на заміри | Ви виїжджаєте на заміри безкоштовно? |
| Формати | площі 20–40 / 40–70 / 70–120 м² | Ваші реальні межі |

Гарантію на роботи я **не вказував навмисно** — щоб ви самі назвали строк.
Якщо даєте гарантію, це сильний аргумент: додайте її в блок довіри.

### 7. Фотографії

Замініть файли в `assets/img/`, зберігши назви — розмітка не зміниться.
Або покладіть оригінали в `_source/`, пропишіть їх у `build_images.py` і запустіть:

```bash
python build_images.py
```

Скрипт сам зробить `jpg` + `webp` у двох розмірах.

## Публікація

Сайт уже опублікований через **GitHub Pages** (гілка `main`, корінь репозиторію).
Кожен `git push` оновлює живий сайт за 1–2 хвилини.

### Свій домен

1. Купіть домен (`.com.ua` ≈ 200–300 ₴/рік).
2. У налаштуваннях репозиторію → **Settings → Pages → Custom domain** впишіть його.
3. У панелі реєстратора додайте DNS-записи:

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
CNAME www  serhii0304.github.io
```

4. Увімкніть **Enforce HTTPS**.
5. Замініть адресу `https://serhii0304.github.io/aframe-zhytomyr/` на свій домен
   у `index.html` (теги `canonical`, `og:url`, `og:image`, JSON-LD), `robots.txt` і `sitemap.xml`.

## Що всередині

- Адаптив від 320 px, окрема мобільна панель дій (дзвінок / Viber / заявка)

## Фотографії

Знімки взяті з оголошення на OLX (8 файлів), колаж розрізано на окремі кадри —
разом 11 зображень. Оригінали лежать у `_source/` і не публікуються (`.gitignore`).

### Маркування походження — не прибирайте його

Не всі фото в оголошенні зняті власником. Розмір файлу це показує однозначно:
OLX стискає завантажене до 1600 px по довшій стороні, але ніколи не збільшує.

| Файли | Оригінал | Походження |
|---|---|---|
| `exterior-1`, `interior-1`, `interior-2`, `interior-3` | 1200×1600 | знято телефоном — **власна робота** |
| `hero`, `dusk-vertical`, `frame-3`, колаж (`frame-1`, `frame-2`, `model-3d`, `model-red`) | 332×498 … 747×498 | взято з інтернету — **приклади** |

Тому в галереї кожна плитка має бейдж `Наш об'єкт` або `Приклад`
(`data-cat="own"` / `data-cat="example"`), під фільтрами стоїть легенда,
а під першим екраном — рядок `.hero__note`.

**Коли власник надішле фото своїх завершених об'єктів** — замініть ними приклади,
поставте `data-cat="own"` і бейдж `gallery__badge--own`. Ідеально — зробити
головним фото власний об'єкт і тоді прибрати `.hero__note`.
